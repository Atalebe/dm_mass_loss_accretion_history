# Zenodo release handoff

The paper repository is public. The owner reports an intention to enable it in Zenodo; account-level enablement is not independently verified.

In Zenodo use the profile menu > GitHub, select Sync now, and switch on `Atalebe/dm_mass_loss_accretion_history`. Enabling connects the repository. A subsequently published GitHub Release triggers archival ingestion; an ordinary code push is not a published release.

Keep publication separate until the licence, selected tree and reproduction scope are approved. No `.zenodo.json` with a guessed licence, DOI, affiliation, funding or ORCID has been created. `CITATION.cff` supplies author and repository information but needs the approved version and rights metadata before archival publication.

After release, inspect the Zenodo title, creator, files, version, licence and actual DOI. Only then replace the manuscript's interim availability text and add a DOI badge.
