# Recovered legacy reproduction materials

This extension preserves checked scientific payload from four earlier evidence packages. Original null arrays, ordered IDs, seeds and per-permutation hashes are retained rather than replaced with new random streams. Acquisition entrypoints, local paths, machine records, private operational logbooks and deliberate failed fixtures are excluded. `provenance/legacy_source_map.json` records archive and member hashes, including the exact numerical functions selected from larger source files.

`tools/replay_legacy.py` reproduces 15 formation/central/extended model grids, nine BolshoiP baseline/threshold model grids, 27 recorded-loss population fits, and 36 AI-assisted second-implementation checks (six four-epoch TNG,15 linear-loss and15 spline-loss). The full option verifies all18,000 original 1,000-draw formation/threshold permutations (468,000 candidate statistics), and all360,000 joint minima from the separate 10,000-draw calculations. The latter implementation retained only a minimum per draw, not every candidate-wise null statistic. No such missing per-candidate archive is claimed.

Run after verified integration into the paper repository:

```bash
bash run_legacy_no_exit.sh
bash run_legacy_no_exit.sh --full-nulls
```

The first invocation checks all saved summaries and replays three draws per case. The second repeats the entire originally saved streams. Both refuse existing output directories. The outer wrapper preserves the caller and records the child status; `COMPLETION.json` is required for a successful result. For batch automation use the direct Python CLI and its nonzero failure status.

The recorded full replay used Python3.13.5, NumPy2.3.5 and pandas2.2.3. A separate environment is appropriate; no installation or dependency change is automatic. Existing original formation values are read as archived. The single previously explained CSV-threshold case is not reopened or replaced.

These are replays of exposed data, not independent statistical replication. Global residual exchangeability and full-population formation identification remain unestablished. Both ABA26-001 and ABA26-002 stay scientifically open. No public licence, visibility change or DOI is authorized by the file transfer.

The large upstream raw trees, failed-download receipts and the separate original per-root reviewer extraction remain distinct provenance layers. Their absence here is not repaired by inventing a source or recomputing different random streams. Some secondary figure/summary producers remain outside the default end-to-end command; consult the32-asset reproduction map.
