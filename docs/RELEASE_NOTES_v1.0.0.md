# Analysis materials v1.0.0

First archival release accompanying **Mass-loss dependence of accretion-history correlations in dark-matter halo velocity structure**, by Stephen Atalebe.

The release contains the checked article and supplement, original source and executable verification tools, selected per-object catalogues and matrices, exact sample identities, full-precision summaries, and saved resampling and spatial-deletion outputs. The 32-asset reproduction map states what is executable from these inputs and what remains upstream or preserved-only evidence.

The original 48,000 author-design permutations retain all 26 candidate values (1,248,000 statistics). The separate 10,000-draw implementation retains 360,000 joint minima across 36 models; it is not pooled with the author-design experiments. Archived-stream replay is reproducibility, not additional confirmation. Both scientific audit findings remain open at their stated inference/population boundaries.

Run `bash run_all_no_exit.sh` for the combined default checks, or append `--full-nulls` to replay every saved stream. Direct Python commands provide nonzero failure status for automation. The no-exit wrappers preserve interactive terminals and require a valid completion record. No automatic package installation occurs.
